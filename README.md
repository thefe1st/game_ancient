# Tantalus / Тантал

Комедийная 2D-головоломка на **Godot 4.5.1 standard**. **Версия 0.5.0: 25 испытаний + глава «Побег из Тартара» из шести связанных залов. Не релиз для Steam.**

## Играть
Windows: распаковать архив целиком и запустить `Tantalus.exe`. Godot устанавливать не нужно.
Linux: `chmod +x Tantalus.x86_64`, затем `./Tantalus.x86_64`.
Из исходников: импортировать `project.godot` в Godot 4.5.1 и нажать F5.

Ранние сборки не подписаны. Не отключайте защиту ОС ради запуска; исходники открываются в Godot. Лицензии движка и его зависимостей — `docs/licenses/`, в сборках — папка `licenses/`.

## Новое в 0.5.0 — Побег из Тартара
- **Одна последовательная глава, шесть залов**, контрольные точки на границах залов и три необязательные амфоры. Это ещё не бесшовный открытый мир: переходы односторонние, для пропущенных секретов нужен новый забег.
- **Эхо**: T начинает/останавливает запись движения до 6 игровых секунд; F воспроизводит её. На геймпаде — D-pad вверх/вниз. Призрачный двойник в конце остаётся на месте, удерживает плиту и замолкает. Новая запись заменяет предыдущую.
- Эхо повторяет сохранённую траекторию, не запускает новую физику, не толкает камни, не переносит факел и не собирает секреты. Шумный повтор отвлекает Цербера.
- Комбинации эха с камнем, световым уступом, питаемой переправой и стражем. Врата требуют удержания всех плит и G у выхода.
- Контрольная точка сохраняет **номер зала**, найденные амфоры, суммарное время и насмешки. При загрузке зал начинается заново: запись эха и расстановка предметов не сохраняются. R/«Заново — этот зал» сбрасывает только зал, без обнуления времени. «Заново» после финала — полный новый забег.
- Четвёртая вкладка в меню испытаний. Завершённый 25-й уровень открывает главу без сброса старых слотов и рекордов; формат сохранений остаётся v2 с необязательным полем escape.
- 12 переназначаемых действий. Старые назначения T/F сохраняются, новые действия получают свободные клавиши. Точные клавиши смотри в «Управление».
- Графика/звуки остаются авторскими процедурными заглушками прототипа. Боя, нити Ариадны и контрактов богов пока нет.

## Что добавлено в 0.4.0
- **25 испытаний**: новый акт III «Соседи по наказанию» с девятью уровнями.
- Данаиды: перенос воды в протекающем сосуде. Приседание предотвращает утечку; воду нужно сдать у колодца. Недостаточный объём не принимается.
- Сизиф: камень активирует нажимную плиту и открывает световые уступы, пока остаётся на месте.
- Иксион: вертикальное колесо-подъёмник и пересадка на движущуюся лодку.
- Комбинации сосуд/Цербер, камень/страж, вода/переправа.
- Отдельное **Управление** в главном меню и паузе. Сочетание для факела показано в начале справки, не спрятано внизу списка. Оно учитывает remap: по умолчанию S + G, на геймпаде B + RB / ○ + R1.
- Нижний HUD больше не перечисляет все кнопки: только пауза/доступ к управлению и Оракул.
- После завершённого финала 0.3 открывается третий акт без сброса слотов.

## Добавлено в 0.3.0
- **16 уровней**: семь испытаний сада и девять Подземного мира.
- Лодки Харона: стоят во время шумной ходьбы и плывут, когда пассажир замер или крадётся. Автоматические лодки для прыжков между платформами; ночная лодка требует света.
- Переносимые факелы: взять/оставить действием, присесть + действие — погасить/зажечь. Световой приёмник включается только от оставленного горящего факела; включает уступ или переправу.
- Комбинированные испытания: вода + переправа, свет + отражение, лодка + Цербер, ночной финал второго акта.
- Падение в Стикс безопасно возвращает на первый берег. Собранные награды и оставленный факел сохраняются до ручного рестарта; время и насмешки не обнуляются.
- Старые M1/M2-слоты сохраняются. После завершённого девятого уровня открывается десятый; старые индексы и версия формата 2 не изменены.
- Новые звуковые заглушки всплеска и включения света; исправлена высота крупных подсказок.

## Уже реализовано в 0.2.0
- **На тот момент 9 уровней**: семь испытаний сада и два новых в Подземном мире — тень и Цербер.
- **Три независимых слота**. Прогресс M1 автоматически переносится в первый; `progress.cfg` не удаляется. Если все 7 испытаний M1 пройдены, Подземный мир открывается сразу. Запись через временный файл, резервная копия и восстановление при ошибке. Сброс — только после подтверждения, старые файлы архивируются.
- Настройки: master/music/effects, mute, fullscreen/F11, VSync, язык RU/EN, крупный игровой текст, reduced motion, спокойный режим ×0.7.
- Переназначение 10 клавиатурных действий, проверка конфликтов, сброс к стандарту. Подсказки HUD меняются вместе с назначениями.
- Базовая поддержка геймпада, адаптация текстовых обозначений Xbox/PlayStation к последнему устройству ввода. Физические устройства ещё требуют ручного теста.
- Спокойный режим открывает прогресс, но его времена хранятся отдельно от обычных рекордов. Таймер считает реальное игровое время без паузы.
- Настройки доступны из паузы. Навигация по меню — мышь, клавиатура или геймпад.

## Управление по умолчанию
| Клавиатура | Xbox / PlayStation | Действие |
|---|---|---|
| A/D, ←/→ | Стик / D-pad влево/вправо | Движение |
| T | D-pad вверх | Записать/остановить эхо (глава IV) |
| F | D-pad вниз | Повторить эхо (глава IV) |
| Space/W/↑ | A / × | Прыжок |
| S/↓ | B / ○ | Присесть, тихое движение |
| Shift | LB / L1 | Пятиться |
| E | X / □ | Глаза |
| G | RB / R1 | Взаимодействовать с факелом |
| H | Y / △ | Оракул |
| Esc | Start / Options | Пауза |
| R | В меню паузы | Рестарт |
| M | В настройках | Звук |
| F11 | В настройках | Полный экран |

Сосуд Данаид: действие у источника — взять/наполнить, у колодца — сдать. Приседание удерживает воду. Факел: действие — взять/оставить; присесть + действие — погасить/зажечь.

После переназначения действия используются выбранные клавиши. Стрелки/W остаются дополнительными только пока соответствующая основная клавиша стандартная. Esc, Enter, Tab и F11 зарезервированы для меню. Если нужно поменять занятые клавиши местами, сначала освободить одну временным назначением. Переназначение геймпада пока не реализовано.

## Проверки и экспорт
```bash
godot --headless --path . --editor --import --quit
godot --headless --path . --script res://tests/run_tests.gd
XDG_DATA_HOME=$(mktemp -d) godot --headless --path . --script res://tests/runtime_tests.gd
XDG_DATA_HOME=$(mktemp -d) godot --headless --path . --script res://tests/m2_tests.gd
XDG_DATA_HOME=$(mktemp -d) godot --headless --path . --script res://tests/m3_tests.gd
XDG_DATA_HOME=$(mktemp -d) godot --headless --path . --script res://tests/m4_tests.gd
mkdir -p build/windows build/linux
godot --headless --path . --export-release Windows build/windows/Tantalus.exe
godot --headless --path . --export-release Linux build/linux/Tantalus.x86_64
```
`m2_tests.gd`, `m3_tests.gd` и `m4_tests.gd` пишут тестовые профили и должен запускаться только в изолированном пользовательском каталоге. Для Windows/macOS вместо XDG_DATA_HOME использовать отдельную тестовую учётную запись или среду. Для экспорта нужны шаблоны **4.5.1.stable**.

GitHub Actions выполняет импорт, тесты и экспорт Windows/Linux. ZIP-артефакты — в Actions → workflow → Artifacts, если workflow разрешён настройками репозитория. Локальная успешная проверка не означает, что удалённый workflow уже прошёл.
