# Tantalus / Тантал

Десктопная 2D-головоломка о Тантале. **Версия 0.1.0 — M1, ядро разработки, не релиз для Steam.**

## Запустить
1. Установить **Godot 4.5.1 standard** (не .NET).
2. Импортировать `project.godot`, нажать F6/F5 (F5 — запуск проекта).
3. «Продолжить» запускает последнее открытое испытание. Новые уровни открываются по порядку.

Windows-сборка: распаковать архив целиком и запустить `Tantalus.exe`. Linux: `chmod +x Tantalus.x86_64`, затем `./Tantalus.x86_64`. Ранние сборки не подписаны. Не отключайте защиту ОС ради их запуска; исходники можно открыть в Godot.

## Уже работает
- Семь уровней: Голод, Взгляд, Жажда, Бегство, Отражение, Камень Сизифа, Пир.
- Ходьба, прыжок, coyote time 100 мс, буфер прыжка 120 мс, приседание, движение спиной, закрывание глаз.
- Ускользающий плод, односторонняя платформа, зеркало, толкаемый камень и поднимающаяся вода.
- Подсказки Оракула, счётчик насмешек, быстрый рестарт.
- Меню, выбор открытых уровней, пауза при потере фокуса, один локальный профиль, лучшие времена.
- RU/EN, синтезированные музыкальные и звуковые заглушки, выключение звука, уменьшение декоративного движения.
- Базовое управление геймпадом (не проверено на физическом устройстве).

## Управление
| Клавиатура | Геймпад (Xbox обозначения) | Действие |
|---|---|---|
| A/D, ←/→ | Левый стик / D-pad | Идти |
| Space/W/↑ | A | Прыжок |
| S/↓ | B | Присесть |
| Shift | LB | Пятиться без разворота |
| E | X | Закрыть/открыть глаза |
| H | Y | Оракул |
| Esc | Start | Пауза |
| R | В меню паузы | Рестарт |
| M | В главном меню | Звук |

Меню: мышь, стрелки + Enter, D-pad + A. Клавиша R сбрасывает текущее испытание, но не разблокированные уровни.

## Проверки и сборка
```bash
godot --headless --path . --editor --import --quit
godot --headless --path . --script res://tests/run_tests.gd
mkdir -p build/windows build/linux
godot --headless --path . --export-release Windows build/windows/Tantalus.exe
godot --headless --path . --export-release Linux build/linux/Tantalus.x86_64
```
Для экспорта установить шаблоны **4.5.1.stable** через Godot. GitHub Actions делает импорт, тесты и экспорт обеих платформ. Архивы находятся в Actions → workflow → Artifacts, если workflow разрешён настройками репозитория.

## Границы этой версии
Это перенос механик, а не обещание готовой игры на 3–5 часов. Графика — сменяемые силуэтные заглушки. Нет Steam SDK/Cloud/достижений, 36 уровней, трёх слотов, переназначения клавиш и отдельного микшера. Windows-сборка экспортируется, но ещё требует ручного теста на Windows. См. `docs/ROADMAP.md`, `docs/TESTING.md`, `docs/STEAM.md`.

Прототип HTML сохранён в `prototype/` как референс; игра его не использует. Исходники, данные уровней и локализация разделены. Внешних плагинов и зависимостей нет.
