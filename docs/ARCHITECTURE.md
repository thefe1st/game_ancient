# Архитектура M1

`scenes/main.tscn` — точка входа. `scripts/main.gd` читает устройства ввода, управляет меню и передаёт команды симуляции. `scripts/simulation.gd` не зависит от сцены, звука, Steam и ввода; получает `{move, jump, crouch, back, eyes}` и выдаёт состояние и события.

Физика: детерминированный ручной решатель AABB для пола, односторонних платформ и камня. Он выбран для воспроизводимых headless-тестов. Склоны, вращающиеся поверхности, движущиеся лодки и более сложные коллизии ещё не реализованы; перед актом III потребуется расширить решатель либо мигрировать на CharacterBody2D с новым набором тестов.

`rules.gd` — чистые функции наказаний. `physics_config.gd` — общий набор констант. `levels/act_01.json` — семь карточек геометрии и правил. `localization/*.json` — все игровые тексты. `garden_view.gd` — заменяемая визуализация состояния, сейчас процедурные плейсхолдеры без импортированных спрайтов.

Autoloads:
- Settings — язык, звук и reduced motion.
- SaveManager — один профиль, лучшие времена, запись временного файла и переименование.
- AudioManager — оригинальные синтезированные WAV, пул эффектов, музыкальный цикл.
- SteamManager — отключён; реальные вызовы Steam запрещены до M5.

Нет отдельного GameState singleton: состояние уровня принадлежит Simulation, прогресс — SaveManager. Дублировать состояние в ещё одном singleton не нужно на M1. Локализация JSON вместо CSV — сознательный компактный старт; импорт в PO/CSV планируется при внедрении редакторского pipeline в M2.

Симуляция обновляется при 60 Гц, отрисовка независима. Тесты дополнительно проверяют решения при 30/120 Гц. Изменение настроек не влияет на правила. reduced motion отключает декоративные волны, частицы и колебания шага, но не физическое движение персонажа/плода.

Внутреннее разрешение M1: 960×540 (сохраняет координаты прототипа), окно по умолчанию 1280×720, масштаб `canvas_items`. Переход на финальное 1920×1080 должен происходить вместе с финальными ассетами и UI, не растягиванием координат физики.
