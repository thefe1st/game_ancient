# Архитектура 0.4.0

`main.tscn` / `main.gd`: меню и маршруты UI, чтение InputMap, real-time таймер, сохранение победы, последний тип ввода. `simulation.gd`: детерминированные платформы, вода, плод, камень, тень и шум; получает команды, отдаёт состояние и события. `rules.gd`: чистые проверяемые функции. `garden_view.gd`: сменяемая визуализация состояния. `level_catalog.gd`: объединяет JSON первого и второго актов.

Физика — ручной AABB/one-way solver, не CharacterBody2D. Он поддерживает нынешние механики и воспроизводимость тестов. Склоны и колесо пока отсутствуют. `platform_world.gd` хранит лодки, их dx/dy и активные поверхности (берега, уступы, световые платформы). Simulation переносит стоящего пассажира перед собственным движением, затем записывает boat-index приземления. Горизонтальный/вертикальный перенос проверен при 30/60/120 Гц. На прыжок скорость носителя не передаётся.

## Autoloads
- Settings: язык, громкости, fullscreen, VSync, доступность, валидированные привязки InputMap. Событие changed обновляет микшер. Esc/Enter/Tab/F11 не могут стать игровыми назначениями. Клавиатурные псевдонимы убираются при смене основной клавиши, навигация ui_* не затрагивается.
- SaveManager: version 2, три профиля, активный слот, нормальные и assisted времена. Старый progress.cfg читается в слот 0 и сохраняется целиком нетронутым. Запись завершения в best_times или assisted_times открывает следующий существующий уровень. Это сохраняет прогресс финалов M1/M2 при добавлении новых сцен, без смены формата или перестановки индексов. Новые записи — progress_slot_N.cfg. Предыдущая версия — .bak. Неизвестная будущая версия защищена от записи. Сброс архивирует файлы с уникальным суффиксом.
- AudioManager: master/music/effects, пул WAV-эффектов и музыкальная заглушка. Голосовой шины нет, так как озвучки нет; добавить при внедрении голосов.
- SteamManager: явно выключен. Никакого SDK в этой версии.

GameState не дублирует Simulation/SaveManager. Тексты локализованы в JSON RU/EN; стандартный CSV/PO pipeline пока отложен. Подсказки контроллера — текст, не полноценный набор glyph-ассетов. Переназначение кнопок геймпада пока не доступно.

## Время и доступность
Физика 60 Гц, тесты решений дополнительно 30/120 Гц. Спокойный режим передаёт 0.7×delta симуляции; таймер рекорда продолжает считать настоящие секунды без меню/паузы. Флаг assisted защёлкивается: выключение спокойного режима перед победой не делает рекорд обычным. Настройки из паузы не запускают симуляцию.

reduced_motion убирает декоративные колебания, но не движение объектов головоломки. Large text увеличивает игровой HUD, меню используют отдельные читаемые размеры. Внутренние координаты 960×540, canvas_items scaling; 16:10 допускает letterboxing. Реальные Deck/контроллеры ещё не сертифицированы.

## Свет и восстановление
Факел описан torch_x/carried_torch/torch_lit; G берёт/оставляет, crouch+G переключает пламя. Приёмник требует оставленный источник внутри радиуса. Карта световых поверхностей перестраивается из JSON без изменения статических платформ. Положение факела/лодок — временное состояние текущего уровня, в профиль не записывается.

Падение под область банков вызывает soft_respawn; Цербер использует тот же возврат после предупреждения. Награды и оставленный свет сохраняются; ручной reset начинает уровень заново. Во время паузы/настроек Simulation.step не вызывается: лодки, физика, шум и таймер стоят.

## Сосуды и нажимные плиты (0.4)
Simulation хранит vessel_carried/vessel_water/water_delivered. Действие у источника наполняет сосуд, у цели принимает достаточную воду. Leak применяется один раз за шаг; crouch-команда отменяет его. update_light объединяет обычный приёмник, нажимную плиту и доставленную воду. Это общий сигнал для световых платформ и powered-переправы.

Уровни без плода должны дополнительно выполнить доставку; это предотвращает случайную мгновенную победу. Нажимная плита также входит в условие победы. soft_respawn сохраняет сосуд и награды; полный reset их очищает. Catalog добавляет act_03.json в конец: ни один прежний индекс не переупорядочен. Профиль остаётся version 2.

## M5: глава и эхо
`levels/act_04.json` добавляет один каталоговый индекс 25 с массивом rooms; старые 0..24 неизменны. Main ведёт номер зала и суммарные метрики. Simulation завершает зал только при открытых вратах, заземлении героя и interact рядом с exit. При смене зала Main сбрасывает Simulation и сохраняет checkpoint.
`echo_track.gd` — чистый RefCounted со снимками pos/height/face/eyes/grounded/noise/t. Ограничение 6 игровых секунд / 721 снимок; положение линейно интерполируется. После конца ghost.holding, noise=0. Никаких собственных столкновений, предметов и повторных взаимодействий. Плиты учитывают ступни заземлённого героя/эха, камень — только на полу. Guardian слушает шумное эхо в пределах echo_hearing.
Сохранение v2 имеет необязательный словарь progress.escape, отдельный для каждого слота. Старые данные дают fresh_escape. Запись при старте/переходе/секрете/паузе/выходе/рестарте. Сохраняются только room, relics, seconds, taunts, assisted, started; не состояние мира и не запись. Пауза останавливает игровую симуляцию и воспроизведение. Мягкий возврат с реки сохраняет эхо; ручной рестарт очищает его.
