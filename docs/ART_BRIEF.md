# 2D-ассеты: следующая художественная веха

Для этой версии сторонние ассеты не понадобились. Новые силуэты/иконки и звуки — сменяемые оригинальные заглушки. 3D-сервисы не являются зависимостью проекта: игра строится вокруг бокового 2D-вида. 3D-модель можно позднее использовать для рендера спрайтов, но это отдельный pipeline.

## Приоритет
1. Тантал: читаемый профиль, выразительная поза, idle/run/backwards/crouch/jump/eyes.
2. Цербер: три раздельные головы, sleep/wake/bark, без мелькания.
3. Плод: idle/flee/legs/eat; затем факел lit/off и амфора.
4. Фоны сада/подземного мира, после утверждения персонажей.

Стиль: чернофигурная древнегреческая керамика, терракота #C8683A/#D98A4E, чернила #1B120C, процарапанные детали #F3DCC0. Никаких чужих логотипов, псевдотекста, глянцевого 3D, заимствований конкретных современных персонажей.

## Промт для концепта Тантала
Создай оригинальный концепт персонажа для 2D-пазл-платформера: древнегреческий царь Тантал, вид строго сбоку, полный рост, чёрнофигурная вазопись, чёрный силуэт и редкие кремовые процарапанные линии, простая туника, выразительные руки и читаемое направление лица. Единый силуэт, никаких букв, рамок, фона, водяных знаков, перспективы и современного оружия. Прозрачный PNG, 1024×1024, одна фигура по центру с одинаковыми отступами. Это концепт, не готовая анимация.

## Промт для концепта Цербера
Оригинальный трёхголовый пёс для той же 2D-игры, боковой вид, три отчётливые головы, добродушно-угрожающий комедийный характер, чёрнофигурная керамика, чёрный силуэт, кремовые внутренние детали, без букв и фона, прозрачный PNG 1024×1024. Все головы принадлежат одному телу; четыре лапы, один хвост; никаких лишних конечностей. Не копируй существующие игровые дизайны.

## Для анимации после утверждения концепта
Не просить генератор одновременно изобретать стиль и делать полноценную sprite sheet. Сначала выбрать один концепт. Затем отдельные 8-кадровые циклы в боковом виде, фиксированный pivot у стоп, одинаковое освещение/масштаб/контур, прозрачный PNG, кадры 256×256; экспорт каждого кадра плюс sheet 2048×256. Проверить каждый кадр, анатомию и петлю вручную. Контур должен оставаться различимым при высоте героя ~56 пикселей в текущем viewport.

## Лицензии
У бесплатного пакета проверить фактический файл лицензии и коммерческое использование — слово «free» не достаточно. Для AI-ассетов сохранить условия сервиса/тарифа, дату, запрос и исходные файлы; бесплатный тариф может ограничивать коммерческие права. Проверять права отдельно для каждого сервиса, не обещать их по одному названию. Перед Steam-выходом провести аудит и заполнить AI-disclosure по действующим правилам платформы. Добавленные ассеты должны быть заменяемыми, с реестром происхождения.
