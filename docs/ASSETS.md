# Замена заглушек

M1 использует процедурные силуэты и синтез WAV. Импортированных изображений, чужих музыкальных записей и плагинов нет. Перед коммерческим релизом провести аудит прав, включая шрифты движка и любые будущие ассеты. Проект не получает автоматически MIT-лицензию.

Финальный арт: персонаж (idle/run/backwards/crouch/jump/eyes), плод (idle/flee/legs/eat), дерево, платформа, камень, отражение, вода, частицы аромата, фон сада, меандр, UI-кнопки и glyphs геймпада. Палитра: терракота #C8683A/#D98A4E, силуэт #1B120C, детали #F3DCC0. Арт меняется в garden_view, не в симуляции.

Звук: шаг ~50 мс, прыжок ~200 мс, ускользание/насмешка ~650 мс, глаза ~200 мс, вода ~400 мс, хруст ~120 мс, победа ~900 мс, музыкальный placeholder 12 с. Нужны отдельные финальные треки для каждого акта, разнообразные насмешки, грохот камня и авлос. Озвучка пока отсутствует.
