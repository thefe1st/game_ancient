# План разработки

- [x] M1a: Godot-проект, семь правил, управление, deterministic simulation.
- [x] M1b: звуковые и визуальные заглушки, headless-тесты.
- [x] M1c: экспорт Windows/Linux, начальное меню и профиль прогресса.
- [ ] M1d: ручной плейтест Windows и физического геймпада; исправления ощущений.
- [ ] M2: полноценные настройки (микшер, fullscreen, VSync, rebind), 3 слота, доступность, локализационный pipeline, UI под Steam Deck.
- [ ] M3: карточки и уровни актов I–II, тень/шум/лодки.
- [ ] M4: акты III–IV, финал, амфоры и режим испытаний.
- [ ] M5: реальный GodotSteam, достижения, статистика, Cloud, лидерборды и Overlay.
- [ ] M6: финальные ассеты и аудио, полировка, баланс, профилирование.
- [ ] M7: подписанные/проверенные релизные сборки, SteamPipe, демо, витрина и тестирование на устройствах.

Следующая задача: проверить M1 на компьютере пользователя, затем реализовать M2 и вертикальный срез второго акта. Не называть scaffold SteamManager подключённой интеграцией.
