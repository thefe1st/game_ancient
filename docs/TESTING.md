# Проверка M1

Автотесты: `godot --headless --path . --script res://tests/run_tests.gd`.
Проверяются чистые правила, решения всех 7 уровней на 30/60/120 Гц, прыжок, landing, coyote time, jump buffer, сохранение ориентации при ходьбе спиной, неудачные подходы и одинаковые ключи локализации.

`tests/visual_capture.gd` — локальный QA-скрипт для capture; нуждается в графическом дисплее и существующей папке `/data/qa`. Не входит в релиз. Не запускать на пользовательском профиле: скрипт разблокирует уровни и записывает тестовый прогресс. Для изоляции задавать отдельный XDG_DATA_HOME. Он снимает меню RU/EN, семь уровней, паузу, победу, глаза и подсказки.

## Локальный результат M1

- Godot 4.5.1: импорт без ошибок.
- 89 логических проверок + 17 runtime-проверок меню/паузы/фокуса/сохранений: 106 проверок, 0 ошибок.
- Решения всех семи уровней при 30/60/120 Гц проверены детерминированным ботом.
- Визуальные экраны сняты и просмотрены на виртуальном Linux-дисплее; найденные наложения устранены.
- Экспорт Windows/Linux выполнен локально. Это НЕ ручной тест Windows и НЕ сертификация Steam Deck.

Runtime-проверка записывает тестовое сохранение: запускать с отдельным `XDG_DATA_HOME`, например `XDG_DATA_HOME=$(mktemp -d) godot --headless --path . --script res://tests/runtime_tests.gd`.

## Ручная приёмка
- [ ] Windows: запуск распакованной сборки, звук слышен, нет ошибок.
- [ ] Пройти каждый уровень без просмотра решения; записать непонятные моменты.
- [ ] R сбрасывает уровень; Esc приостанавливает симуляцию.
- [ ] Alt-Tab автоматически ставит игру на паузу.
- [ ] Перезапуск приложения сохраняет открытые уровни и времена.
- [ ] RU/EN не теряет текст и не вызывает переполнение.
- [ ] M и настройки выключают все звуки.
- [ ] Геймпад: пройти игру, все меню доступны без мыши.
- [ ] 1280×800: проверить реальные Steam Deck / Linux-устройство.
- [ ] Не слышно щелчков/клиппинга музыки, эффекты не раздражают при повторении.

Экспорт под Windows не является доказательством работы на Windows. Аналогично, виртуальный графический smoke-test Linux не заменяет тест на реальном GPU/устройстве. Не заявлять 60 FPS на слабом ноутбуке до профилирования.
